Use `Button` for any action; pick `cta` (yellow) on the website and `primary` (mint) inside decks and documents.

```jsx
<Button variant="cta">Apply now</Button>
<Button variant="outline" size="s">Download deck</Button>
```

Variants: `cta` (#FFF70A on #12130F — the website primary), `primary` (mint on #04412E), `navy`, `outline`, `ghostOnNavy` (for use on navy panels). Sizes `s` / `m` / `l`; `m` is 19px at 15/30px padding. Never place two primary buttons in one view, and never restyle a button with a shadow.
