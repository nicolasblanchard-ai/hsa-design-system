Use `StepCard` in a flex row with a `--green-rule` connector behind the circles to build the timeline archetype.

```jsx
<StepCard step="1" phase="Weeks 1&ndash;4" title="Foundations">Team &amp; roles, problem&ndash;solution fit.</StepCard>
<StepCard step="&rarr;" phase="Demo Day" title="The raise" final>Pitch to a curated investor room.</StepCard>
```

Exactly one `final` step per timeline — it is the only yellow circle.
