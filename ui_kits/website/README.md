# Website UI kit

A recreation of the public site's structure in the design system's own components —
header, hero, program cards, partner cards, waitlist form, navy footer.

**Source.** hsgstartaccelerator.org (structure and the yellow CTA treatment) plus the
Partner Deck for content and card patterns. No site source code was available, so this
is a system-faithful rebuild rather than a pixel recreation — the live site's exact
spacing and section order may differ. A new site is planned on top of this system.

**Rules it demonstrates**
- Yellow `#FFF70A` is the only primary action; mint stays structural (top rule, card accents, bullets).
- The 7px mint rule sits above the header, exactly as on a slide.
- Cards are top-accent or tint; no shadows anywhere.
- The navy CTA band carries a clipped cube watermark at .15 opacity.

Open `index.html`. Components resolve from the compiled bundle at the project root.
